# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Describe the problem, the affected version or commit, and the steps to reproduce it. Leave out real member data, secrets and access tokens.

You will get an answer in the advisory. The fix is developed in a private fork of the advisory and published together with the advisory once a release is available.

## Supported versions

Only the latest `main` is supported. Fixes are not backported to older commits or releases.
