# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Describe the problem, the affected commit, and the steps to reproduce it. Leave out real member data, secrets and access tokens.

You will get an answer in the advisory. The fix is developed in the advisory's private fork, merged into `main` and published together with the advisory.

For maintainers: the **Report a vulnerability** button exists only while private vulnerability reporting is switched on in the repository settings (the "Private vulnerability reporting" switch on the security settings page). Keep it on.

## Supported versions

There are no releases yet. Only the latest commit on `main` is supported; fixes land there and are not backported to older commits. Once releases exist, this section will name the supported ones.
